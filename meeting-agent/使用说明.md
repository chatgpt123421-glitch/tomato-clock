# 🤖 会议统筹智能体 - 使用说明

## 🚀 即开即用，无需安装依赖！

### 快速开始

#### 方式一：双击运行（推荐）
直接双击 `启动会议智能体.bat` 文件即可运行

#### 方式二：命令行运行
```bash
python meeting_simple.py
```

---

## 📋 功能介绍

| 功能 | 说明 | 使用场景 |
|------|------|----------|
| 📅 **创建会议** | 输入标题、描述、时长 | 需要安排新会议时 |
| 👥 **添加参会人** | 添加姓名、职位、邮箱 | 确定参会人员名单时 |
| 📋 **生成议程** | AI智能生成结构化议程 | 需要会议议程时 |
| ⏰ **推荐时间** | 分析最佳会议时间 | 协调多方时间时 |
| 📝 **整理纪要** | 自动提取要点和行动项 | 会后整理记录时 |
| 💾 **导出文档** | 导出txt格式会议文档 | 需要发送会议纪要给他人时 |

## 🎯 使用示例

### 场景1：组织一次产品评审会

```
1. 📅 创建新会议
   会议标题: 产品评审会
   会议描述: 评审Q2新功能设计
   预计时长: 90

2. 👥 添加参会人员
   选择会议: 1. 产品评审会
   姓名: 张三
   职位: 产品经理
   邮箱: zhangsan@company.com
   (重复添加多人...)

3. 📋 生成会议议程
   选择会议: 1
   → 自动生成6项议程

4. ⏰ 推荐会议时间
   选择会议: 1
   → 获得3个推荐时间段

5. 💾 导出会议文档
   → 生成 "会议_产品评审会_20240115_143022.txt"
```

### 场景2：会后整理纪要

```
5. 📝 整理会议纪要

   ────────────────────────────────────
   主持人: 今天我们讨论新功能方案
   技术: API设计已完成初稿
   产品: 需要增加用户反馈功能
   ...
   END
   
   → 自动生成结构化纪要
   → 提取关键要点、决策事项、行动项
```

## 🔧 系统要求

- **操作系统**: Windows 7/10/11, macOS, Linux
- **Python版本**: Python 3.6 或更高
- **无需安装任何第三方库**

### 检查Python是否安装

打开命令提示符，输入：
```bash
python --version
```

如果显示版本号（如 `Python 3.9.0`），说明已安装。

如果未安装，请访问 https://www.python.org/downloads/ 下载安装。

## 💡 使用技巧

1. **快速演示模式**
   - 首次运行时会询问是否演示
   - 演示模式会自动创建一个完整的示例会议
   - 适合快速了解功能

2. **批量添加参会人**
   - 添加完一位后，系统会自动回到菜单
   - 重复选择"2"继续添加更多人员

3. **导出文档**
   - 导出格式为txt，可用记事本、Word打开
   - 文件命名格式：`会议_[标题]_[日期时间].txt`
   - 包含完整的会议信息和纪要

4. **数据保存**
   - 当前版本数据存储在内存中
   - 退出程序后数据不保留
   - 重要会议请使用"导出文档"功能保存

## ❓ 常见问题

### Q: 双击bat文件闪退？
A: 可能是Python未安装或未添加到环境变量。尝试：
1. 打开命令提示符
2. 输入 `python --version` 检查
3. 如果提示找不到命令，需要安装Python并勾选"Add to PATH"

### Q: 如何保存会议数据？
A: 使用功能7"导出会议文档"，会生成txt文件保存到本地。

### Q: 支持中文吗？
A: 完全支持中文，包括标题、描述、姓名等。

### Q: 想要AI更智能的功能？
A: 可以使用 `meeting_agent.py` 版本，需要：
1. 申请 Anthropic API 密钥
2. 安装依赖：`pip install anthropic`
3. 配置环境变量后运行
