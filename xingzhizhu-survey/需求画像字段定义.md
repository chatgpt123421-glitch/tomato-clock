# 需求画像字段定义（MVP版）

> 用途：客户完成节点一问卷后，家宝/AI输出的标准化摘要
> 目标读者：节点二设计师/AI
> 原则：设计师拿10秒能判断项目全貌，不需要回头看问卷

---

## 一、基础锚点

决定项目规模和资源投入方向。

| 字段 | 数据类型 | 必填 | 示例 |
|------|---------|------|------|
| 常住人口数 | 整数 | 是 | 3人 |
| 人口结构 | 标签数组 | 是 | [夫妻, 1岁婴儿] |
| 房屋面积 | 整数+单位 | 是 | 89㎡ |
| 户型格局 | 字符串 | 是 | 三室一厅一卫 |
| 装修类型 | 枚举 | 是 | 毛坯/二手房翻新/局部改造 |
| 总预算区间 | 枚举 | 是 | 10-15万/15-20万/20-30万/30万以上 |
| 有无户型图 | 布尔 | 是 | 有（已上传）/ 无（待勘测） |
| 预计入住时间 | 枚举 | 否 | 3个月内/半年内/一年内/不着急 |
| 城市/气候区 | 字符串 | 否 | 广州（湿热）/ 北京（干燥寒冷） |

---

## 二、场景分级

从9+N问卷中自动归纳，告诉设计师重点攻哪几个场景。

| 字段 | 数据类型 | 说明 | 示例 |
|------|---------|------|------|
| 核心场景（🔴） | 场景名数组 | 高频使用 + 明确不满意 | [餐厨茶饮, 卫浴漱妆] |
| 次要场景（🟡） | 场景名数组 | 高频但基本满意，或低频但有痛点 | [智慧收纳] |
| 无关场景（⚪） | 场景名数组 | 低频 + 满意，或客户明确表示不需要 | [家庭健身, 居家娱乐] |
| 特殊场景触发 | 标签数组 | N场景中哪些被激活 | [孕产育婴] |

**分级规则（自动计算）：**
- 核心：使用频率="每天" 且 满意度="不满意"
- 次要：使用频率="每天" 且 满意度="基本满意"，或使用频率="偶尔" 且 满意度="不满意"
- 无关：使用频率="偶尔" 且 满意度="满意"，或问卷中明确回答"不需要此场景"

---

## 三、痛点清单

设计师的切入点。每个核心场景必须至少有一条痛点。

| 字段 | 数据类型 | 必填 | 示例 |
|------|---------|------|------|
| 所属场景 | 枚举 | 是 | 餐厨茶饮 |
| 痛点描述 | 文本（≤50字） | 是 | 操作台面不足，两人同时备菜转不开身 |
| 发生频率 | 枚举 | 是 | 每天/每周几次/偶尔 |
| 痛苦程度 | 枚举 | 是 | 严重影响日常/影响心情/偶尔不便 |
| 客户原话 | 文本 | 否 | "两个人在厨房就跟打架一样" |
| 已尝试解决 | 文本 | 否 | 买过置物架，但占台面更挤 |

---

## 四、设计参数

客户明确要的东西，可直接转化为设计需求。

| 字段 | 数据类型 | 必填 | 示例 |
|------|---------|------|------|
| 所属场景 | 枚举 | 是 | 卫浴漱妆 |
| 需求项 | 文本 | 是 | 双台盆 |
| 必要性 | 枚举 | 是 | 必须有/最好有/可有可无 |
| 规格要求 | 文本 | 否 | 台盆长度≥1200mm |
| 风格/品牌偏好 | 文本 | 否 | 喜欢极简风，不接受日式 |
| 预算敏感度 | 枚举 | 否 | 愿为品质加钱/追求性价比/越便宜越好 |

---

## 五、特殊约束

不可妥协的硬性条件，设计师必须遵守。

| 字段 | 数据类型 | 必填 | 示例 |
|------|---------|------|------|
| 约束类型 | 枚举 | 是 | 安全/健康/情感/宠物/法规 |
| 具体描述 | 文本 | 是 | 1岁婴儿会爬，所有家具需圆角防撞 |
| 优先级 | 枚举 | 是 | 绝对不可妥协/尽量满足/提醒即可 |
| 关联场景 | 场景名数组 | 否 | [智慧收纳, 环境优化] |

---

## 六、种草待确认

家宝主动推荐但客户尚未明确接受的项目。

| 字段 | 数据类型 | 必填 | 示例 |
|------|---------|------|------|
| 推荐项 | 文本 | 是 | 餐边柜 |
| 推荐理由 | 文本（≤30字） | 是 | 解决小家电无处放的台面混乱问题 |
| 预估增项成本 | 枚举 | 否 | 2000-5000元 |
| 解决痛点 | 文本 | 否 | 餐厨台面不足 |
| 客户反馈 | 枚举 | 是 | 接受/拒绝/犹豫/未推送 |

---

## 完整示例

**客户背景：** 3口之家（夫妻+1岁女婴），89㎡二手房，预算15-20万，广州。

### 基础锚点
- 常住人口数：3
- 人口结构：[夫妻, 1岁婴儿]
- 房屋面积：89㎡
- 户型格局：三室一厅一卫
- 装修类型：二手房翻新
- 总预算区间：15-20万
- 有无户型图：有（已上传）
- 预计入住时间：半年内
- 城市/气候区：广州（湿热）

### 场景分级
- 核心场景（🔴）：[餐厨茶饮, 卫浴漱妆]
- 次要场景（🟡）：[智慧收纳, 健康睡眠]
- 无关场景（⚪）：[家庭健身, 居家娱乐, 学习成长]
- 特殊场景触发：[孕产育婴]

### 痛点清单
| 场景 | 痛点描述 | 频率 | 程度 |
|------|---------|------|------|
| 餐厨茶饮 | 操作台面不足，两人同时备菜转不开身 | 每天 | 严重影响日常 |
| 餐厨茶饮 | 冰箱塞不下，冷冻室经常爆仓 | 每天 | 影响心情 |
| 卫浴漱妆 | 早高峰单台盆，夫妻洗漱排队 | 每天 | 严重影响日常 |
| 卫浴漱妆 | 给婴儿洗澡要蹲地上，腰酸 | 每天 | 影响心情 |

### 设计参数
| 场景 | 需求项 | 必要性 | 规格要求 |
|------|--------|--------|---------|
| 卫浴漱妆 | 双台盆 | 必须有 | 长度≥1200mm |
| 餐厨茶饮 | 大容量冰箱位 | 必须有 | 双开门，≥500L |
| 餐厨茶饮 | 洗碗机 | 最好有 | 13套以上 |
| 健康睡眠 | 遮光窗帘 | 必须有 | 100%遮光 |

### 特殊约束
| 类型 | 描述 | 优先级 |
|------|------|--------|
| 安全 | 1岁婴儿会爬，所有家具需圆角防撞 | 绝对不可妥协 |
| 安全 | 插座需防误触保护盖 | 绝对不可妥协 |
| 健康 | 广州湿热，全屋需防霉处理 | 尽量满足 |

### 种草待确认
| 推荐项 | 推荐理由 | 客户反馈 |
|--------|---------|---------|
| 餐边柜 | 解决小家电无处放的台面混乱问题 | 犹豫 |
| 软水机 | 广州水质硬，婴儿洗浴更温和 | 未推送 |
| 恒温花洒 | 避免给婴儿洗澡时水温忽冷忽热 | 接受 |
