# 问题库：特殊生活（Special Life）

> 覆盖子场景：孕产育婴、养老守护、宠物生活、诗和远方、二次元
> 原则：这些不是刚需，却是生活的点睛之笔
> 目标：有标签用户≤6题，无标签用户自动跳过

---

## 前置分流题（基础信息中已采集）

**Q0. 家里是否有以下特殊情况？**（基础信息.tags）
- 题型：多选
- 选项：备孕/孕期 / 0-3岁婴儿 / 65岁以上老人 / 养宠物 / 户外/露营/骑行装备多 / 手办/藏品/二次元 / 以上都没有
- 映射画像字段：场景分级.特殊标签

---

## 模块A：孕产育婴（tag含备孕/孕期/婴儿）

**Q1. 需要规划婴儿房或尿布台区域吗？**
- 题型：单选
- 选项：需要独立婴儿房 / 主卧内规划角落即可 / 暂不需要
- 映射画像字段：设计参数.婴儿房
- 价值说明：💡 0-3岁婴儿最好和父母同房不同床，方便夜间照料

---

## 模块B：养老守护（tag含老人）

**Q2. 老人居住最需要什么安全措施？**
- 题型：多选
- 选项：卫生间防滑 / 马桶/淋浴扶手 / 紧急呼救按钮 / 起夜感应灯
- 映射画像字段：设计参数.老人安全
- 价值说明：💡 老人跌倒有一半发生在卫生间，防滑和扶手是刚需

---

## 模块C：宠物生活（tag含宠物）

**Q3. 养什么宠物？需要什么设施？**
- 题型：多选
- 选项：猫（猫爬架/猫砂盆区）/ 狗（活动空间/狗窝）/ 其他 / 阳台防护网/防逃
- 映射画像字段：设计参数.宠物设施
- 价值说明：💡 宠物是家人，它们的舒适度直接影响主人的生活品质

---

## 模块D：诗和远方（tag含户外）

**Q4. 户外装备大概有多少？需要专门收纳区吗？**
- 题型：单选
- 选项：很多（帐篷/骑行/滑雪）/ 少量 / 不需要专门区域
- 映射画像字段：设计参数.户外装备收纳
- 价值说明：💡 户外装备体积大、形状不规则，需要专门的高柜或储物间

---

## 模块E：二次元（tag含二次元）

**Q5. 二次元/藏品需要什么展示或收纳？**
- 题型：单选
- 选项：防尘玻璃展示柜 / 独立电竞/手办房 / 漫画/海报墙
- 映射画像字段：设计参数.二次元空间
- 价值说明：💡 手办怕灰怕光，玻璃柜+内置灯带是最佳方案

## 输出映射规则

**场景分级：**
- tag含任意特殊标签 → 🟡次要场景
- tag=无 或 未选 → ⚪无关场景（自动跳过）

**特殊约束自动生成：**
- tag含备孕/孕期/婴儿 → 约束="孕婴家庭：ENF级环保板材、低甲醛涂料、无尖角家具"
- tag含老人 → 约束="养老守护：地面无高差、通道≥900mm、紧急呼叫"
- tag含宠物 → 约束="宠物家庭：耐抓地板/沙发、易清洁墙面、防逃门窗"

**设计参数提取：**
- Q1=独立房间 → 参数="婴儿房（环保材料+监控位）"
- Q1=主卧角落 → 参数="主卧尿布台/婴儿床区"
- Q2=防滑 → 参数="防滑地砖+淋浴防滑垫"
- Q2=扶手 → 参数="马桶/淋浴扶手"
- Q2=呼救 → 参数="紧急呼救按钮"
- Q3=猫 → 参数="猫爬架区+猫砂盆隐藏位"
- Q3=狗 → 参数="狗窝区+易清洁地面"
- Q3=防护 → 参数="阳台防护网/金刚网纱窗"
- Q4=多 → 参数="户外装备柜（帐篷/骑行/滑雪）"
- Q5=展示柜 → 参数="手办防尘玻璃柜"
