# 问题库：餐厨茶饮（Meal & Tea）

> 覆盖子场景：烹饪、用餐、茶饮/酒水、清洁收纳、社交互动
> 原则：先挖真实习惯，再推种草项；种草与真实需求严格分离
> 目标：通过分流控制题量，高频用户≤12题，低频用户≤5题

---

## 前置分流题

**Q0. 您家平时开火做饭的频率是？**
- 题型：单选
- 选项：
  - 每天1-2餐（→ 模块A+B+C+D+E，完整版）
  - 每周3-5次（→ 模块A+B+C+D+E，完整版）
  - 偶尔/基本外卖（→ 模块B+C+E极简版，跳过A烹饪细节和D清洁收纳）
  - 从不做饭（→ 模块B+C+E极简版，跳过A和D）
- 映射画像字段：场景分级.餐厨茶饮频率锚点

---

## 模块A：烹饪习惯（做饭用户必填）

**Q1. 家里平时主要做什么类型的饭菜？**
- 题型：多选
- 选项：中式爆炒 / 轻食蒸煮 / 烘焙西餐 / 简餐热饭 / 其他
- 映射画像字段：痛点清单.烹饪方式（决定油烟、台面、电器需求）
- 价值说明：💡 中式爆炒需要大吸力油烟机，烘焙需要嵌入烤箱位

**Q2. 平时做饭一般是一个人操作，还是两个人同时在厨房？**
- 题型：单选
- 选项：我一人 / 两人一起 / 轮流做
- 映射画像字段：痛点清单.动线人数
- 价值说明：💡 单人厨房和双人协作厨房的台面、动线完全不同

**Q3. 现在炒菜时，油烟会不会飘到客厅或餐厅，身上有油烟味？**
- 题型：判断题（会/不会）
- 映射画像字段：痛点清单.痛点描述="油烟扩散"
- 价值说明：💡 这决定是否需要更换大功率烟机或调整厨房结构

**Q4. 切菜、备菜的时候，台面是不是经常堆满东西、不够用？**
- 题型：判断题（是/否）
- 映射画像字段：痛点清单.痛点描述="备菜区不足"
- 价值说明：💡 备菜区是厨房使用频率最高的区域

**Q5. 两个人同时在厨房时，会不会互相挡路、转不开身？**
- 题型：判断题（会/不会）
- 映射画像字段：痛点清单.痛点描述="操作动线拥挤"
- 价值说明：💡 这决定是否适合做开放式厨房或扩大门洞

---

## 模块B：用餐习惯（所有用户必填）

**Q6. 工作日的早餐，一般怎么解决？**
- 题型：单选
- 选项：
  - 快速出门，不吃或路上解决
  - 简单在家吃（面包/牛奶/煮蛋）
  - 认真做早餐（煮粥/煎蛋/备菜）
- 映射画像字段：设计参数.早餐场景
- 价值说明：💡 快节奏早餐可能只需要一个小家电区，不需要大餐桌

**Q7. 晚餐是全家人一起吃，还是各自错开时间吃？**
- 题型：单选
- 选项：全家一起吃 / 分两拨吃 / 各自解决
- 映射画像字段：设计参数.晚餐场景
- 价值说明：💡 全家一起吃需要更大的餐桌和更集中的收纳

**Q8. 周末会邀请朋友或亲戚来家里聚餐吗？一般来几个人？**
- 题型：单选
- 选项：不会 / 1-3人 / 4-6人 / 6人以上
- 映射画像字段：设计参数.聚餐场景
- 价值说明：💡 经常聚餐需要考虑餐桌延展或餐厨互动空间

**Q9. 家里的餐桌，除了吃饭还会用来做什么？**
- 题型：多选
- 选项：工作/办公 / 孩子写作业 / 喝茶聊天 / 什么都不做，只吃饭
- 映射画像字段：设计参数.餐桌多功能
- 价值说明：💡 餐桌兼职越多，对桌面大小、灯光、插座要求越高

---

## 模块C：茶饮与酒水（选填，不强制）

**Q10. 家里有喝茶的习惯吗？**
- 题型：单选
- 选项：功夫茶（需要茶台）/ 简单泡茶 / 偶尔喝 / 完全不喝
- 映射画像字段：设计参数.茶酒文化
- 价值说明：💡 功夫茶需要专门的上下水和收纳空间

**Q11. 有喝咖啡的习惯吗？**
- 题型：单选
- 选项：每天手冲/意式 / 胶囊/速溶 / 外面买 / 不喝
- 映射画像字段：设计参数.茶酒文化
- 价值说明：💡 手冲咖啡需要专门的操作台面和插座布置

**Q12. 家里有存酒或平时会小酌吗？**
- 题型：单选
- 选项：有藏酒需要展示 / 偶尔喝点，不用专门存 / 完全不喝
- 映射画像字段：设计参数.茶酒文化
- 价值说明：💡 藏酒需要恒温避光的存储空间

---

## 模块D：清洁收纳（做饭用户必填）

**Q13. 现在的厨房，台面是不是经常被锅碗瓢盆、调料、小家电占满？**
- 题型：判断题（是/否）
- 映射画像字段：痛点清单.痛点描述="收纳空间不足，台面混乱"
- 价值说明：💡 台面混乱通常不是东西多，而是收纳规划不合理

**Q14. 家里的碗一般是谁洗？**
- 题型：单选
- 选项：我手洗 / 轮流洗 / 已经有洗碗机 / 基本不做饭不用洗
- 映射画像字段：设计参数.洗碗方式
- 价值说明：💡 洗碗习惯决定了是否需要预留洗碗机位置

---

## 模块E：社交互动（所有用户必填）

**Q15. 您做饭的时候，喜欢和家人聊聊天、让孩子在旁边看看吗？**
- 题型：判断题（喜欢/不喜欢，希望厨房独立）
- 映射画像字段：设计参数.社交互动
- 价值说明：💡 喜欢互动适合做开放式或半开放式厨房

**Q16. 您希望朋友来家里时，厨房区域看起来整洁、有质感吗？**
- 题型：判断题（是/否）
- 映射画像字段：设计参数.颜值要求
- 价值说明：💡 对厨房颜值有要求会影响材质选择和是否做开放式

以下问题**不由客户直接回答**，而是家宝根据前面答案主动推荐：

| 触发条件 | 种草项 | 推荐理由 | 映射画像字段 |

## 题量控制

| 用户类型 | 必填模块 | 题量 | 预计时长 |
|---------|---------|------|---------|
| 每天/高频做饭 | A+B+C+D+E | 16题 | 3-4分钟 |
| 偶尔/外卖为主 | B+C+E | 8题 | 1-2分钟 |
| 从不做饭 | B+C+E（精简） | 5题 | 1分钟内 |

**注：** 模块C（茶酒）可根据用户前序答案智能跳过。例如Q10=完全不喝、Q11=不喝、Q12=不喝，则自动标记"无茶饮酒水需求"，不再追问。

## 输出映射规则

**场景分级：**
- Q0=每天/每周3-5次 且 （Q3=会 或 Q4=是 或 Q5=会） → 🔴核心场景
- Q0=每周3-5次 且 Q3-Q5均为否 → 🟡次要场景
- Q0=偶尔/从不 且 Q8=不会 → ⚪无关场景

**痛点清单自动生成：**
- Q3=会 → 痛点="油烟扩散至客餐厅"
- Q4=是 → 痛点="备菜区台面不足"
- Q5=会 → 痛点="双人操作时动线拥挤"
- Q13=是 → 痛点="收纳空间不足，台面被杂物占满"

**设计参数提取：**
- Q1=中式爆炒 → 参数="大吸力油烟机（≥20m³/min）"
- Q1=烘焙西餐 → 参数="嵌入式烤箱位"
- Q6=认真做早餐 → 参数="早餐操作区/小家电集中区"
- Q7=全家一起吃 → 参数="家庭聚餐型餐桌"
- Q8=4-6人/6人以上 → 参数="可延展餐桌或大餐桌"
- Q9=工作/办公 → 参数="餐桌旁预留插座/网络"
- Q10=功夫茶 → 参数="茶台上下水位"
- Q14=已经有洗碗机 → 参数="洗碗机（已有，保留位置）"
