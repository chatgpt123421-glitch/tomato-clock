# 问题库：卫浴漱妆（Bathroom & Dressing）

> 覆盖子场景：晨起/睡前动线、漱洗护理、如厕体验、沐浴享受
> 原则：聚焦"时间冲突"和"身体感受"，这是卫浴最真实的痛点
> 目标：通过分流控制题量，高频冲突用户≤12题，低敏用户≤6题

---

## 前置分流题

**Q0. 家里现在有几个卫生间？**
- 题型：单选
- 选项：1个 / 2个 / 3个及以上
- 映射画像字段：基础锚点.卫生间数量

**Q1. 家里常住人口中，早上需要在相似时间段用卫生间的有几人？**
- 题型：单选
- 选项：
  - 1人（→ 模块B+C+D，跳过A动线冲突）
  - 2人（→ 完整版全模块）
  - 3人及以上（→ 完整版全模块，且标记"动线高压"）
- 映射画像字段：场景分级.卫浴冲突指数

---

## 模块A：晨起/睡前动线（2人及以上必填）

**Q2. 早上家里人用卫生间会排队或互相等待吗？**
- 题型：判断题（会/不会）
- 映射画像字段：痛点清单.痛点描述="早高峰卫浴排队"
- 价值说明：💡 排队是卫生间设计失败最明显的信号

**Q3. 排队一般发生在哪个环节？**
- 题型：多选
- 选项：洗漱台 / 马桶 / 淋浴 / 不排队
- 映射画像字段：痛点清单.排队环节
- 价值说明：💡 洗漱排队适合双台盆，马桶排队适合干湿分离/双卫

**Q4. 晚上睡前，夫妻两人能同时洗漱护肤吗？**
- 题型：判断题（能/不能，要轮流）
- 映射画像字段：痛点清单.痛点描述="睡前动线交叉"
- 价值说明：💡 同时洗漱需要足够的镜柜和台面空间

---

## 模块B：漱洗护理（所有用户必填）

**Q5. 洗漱时护肤品、化妆品是放在卫生间还是卧室？**
- 题型：单选
- 选项：全部放卫生间 / 部分放卧室 / 全部放卧室
- 映射画像字段：设计参数.护肤品收纳位置
- 价值说明：💡 放卫生间需要防潮收纳，放卧室需要化妆台/镜

**Q6. 现在的镜子和灯光，化妆护肤时够用吗？**
- 题型：判断题（够用/不够，背光或太暗）
- 映射画像字段：痛点清单.痛点描述="化妆灯光不足"
- 价值说明：💡 化妆需要正面均匀光，普通顶灯会有阴影

**Q7. 有在卫生间吹头发、用卷发棒等电器的习惯吗？**
- 题型：判断题（经常/偶尔/从不）
- 映射画像字段：设计参数.小电器需求
- 价值说明：💡 需要预留插座位置和防潮措施

---

## 模块C：如厕体验（所有用户必填）

**Q8. 马桶区有没有明显的异味问题？**
- 题型：判断题（有/没有）
- 映射画像字段：痛点清单.痛点描述="卫生间异味"
- 价值说明：💡 异味通常来自通风不足或下水道反味

**Q9. 家里有老人或膝盖不便的人吗？起坐马桶时需要扶手支撑吗？**
- 题型：判断题（需要/不需要）
- 映射画像字段：特殊约束.如厕安全
- 价值说明：💡 老人安全是刚性需求，必须提前规划

---

## 模块D：沐浴享受（所有用户必填）

**Q10. 现在的淋浴水温稳定吗？会不会忽冷忽热？**
- 题型：判断题（稳定/忽冷忽热）
- 映射画像字段：痛点清单.痛点描述="水温不稳定"
- 价值说明：💡 忽冷忽热通常是因为水压不稳或热水器位置不合理

**Q11. 家里有人喜欢用浴缸泡澡吗？**
- 题型：单选
- 选项：经常泡 / 想尝试但没条件 / 完全不泡
- 映射画像字段：设计参数.浴缸需求
- 价值说明：💡 浴缸需要足够空间和上下水改造

**Q12. 洗完澡后，卫生间地面会不会到处是水？**
- 题型：判断题（会/不会）
- 映射画像字段：痛点清单.痛点描述="干湿不分离，地面湿滑"
- 价值说明：💡 这直接决定是否要做干湿分离或淋浴房

## 模块E：特殊人群约束（动态插入）

以下根据基础锚点的人口结构自动触发，不直接提问：

| 触发条件 | 约束项 | 说明 |
|---------|--------|------|
| 人口结构含"婴儿/幼儿" | 婴儿洗浴 | 需要婴儿浴盆放置空间和低位取水 |
| 人口结构含"老人/孕妇" | 防滑扶手 | 马桶旁和淋浴区需预留扶手位 |

## 输出映射规则

**场景分级：**
- Q2=会 或 Q3含"洗漱台/马桶" → 🔴核心场景
- Q2=不会 但 Q12=会 → 🟡次要场景（沐浴体验待优化）
- Q2=不会 且 Q12=不会 且 Q8=没有 → ⚪无关场景（满意度高）

**痛点清单自动生成：**
- Q2=会 → 痛点="早高峰卫生间排队"
- Q3含"洗漱台" → 痛点="洗漱台资源不足"
- Q3含"马桶" → 痛点="如厕排队"
- Q6=不够 → 痛点="化妆护肤灯光不足，面部有阴影"
- Q8=有 → 痛点="卫生间异味/通风不良"
- Q10=忽冷忽热 → 痛点="淋浴水温不稳定"
- Q12=会 → 痛点="干湿不分离，地面湿滑且有安全隐患"

**设计参数提取：**
- Q0=1个 且 Q2=会 → 参数="双卫改造或干湿分离优先级高"
- Q5=全部放卫生间 → 参数="镜柜需带防潮收纳"
- Q7=经常 → 参数="台盆旁预留吹风机插座（带防水盖）"
- Q9=需要 → 参数="马桶旁预留扶手安装位"
- Q11=经常泡 → 参数="标准浴缸位（≥1200mm）"
- Q11=想尝试 → 参数="迷你深泡缸位（≥900mm）"
