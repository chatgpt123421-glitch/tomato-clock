# 问题库：衣物洗护（Laundry & Wardrobe）

> 覆盖子场景：脏衣动线、洗涤方式、晾晒烘干、衣柜收纳、熨烫护理
> 原则：从脏衣到净衣，动线决定了家务量
> 目标：高频洗护用户≤8题，低敏用户≤5题

---

## 前置分流题

**Q0. 家里怎么洗衣服？**
- 题型：单选
- 选项：
  - 基本手洗（→ 模块A+B+C，标记"手洗痛点"）
  - 洗衣机（→ 完整版全模块）
  - 洗烘套装/一体机（→ 模块B+C，跳过A洗涤）
  - 高端衣物送洗（→ 模块B+C精简版）
- 映射画像字段：场景分级.洗护方式锚点

---

## 模块A：洗涤动线（手洗/机洗用户必填）

**Q1. 换下来的脏衣服一般扔在哪？**
- 题型：多选
- 选项：固定脏衣篮 / 椅子/沙发/床上 / 直接扔卫生间 / 随手放地上
- 映射画像字段：痛点清单.脏衣动线
- 价值说明：💡 没有固定脏衣篮是家务混乱的第一信号

**Q2. 洗完在哪晾晒/烘干？**
- 题型：多选
- 选项：阳台晾晒 / 烘干机烘干 / 客厅/卧室临时晾 / 卫生间阴干
- 映射画像字段：痛点清单.晾晒位置
- 价值说明：💡 客厅临时晾衣严重影响美观和动线

---

## 模块B：衣柜收纳（所有用户必填）

**Q3. 衣柜现在最大的痛点？**
- 题型：多选
- 选项：挂衣区不够，衣服堆叠 / 找不到衣服，翻来翻去 / 换季收纳麻烦 / 总容量不够，塞不下
- 映射画像字段：痛点清单.衣柜痛点
- 价值说明：💡 衣柜痛点通常不是柜子小，而是分区不合理

**Q4. 有熨烫/护理衣物的需求吗？**
- 题型：单选
- 选项：每天熨，需要熨衣板 / 偶尔需要 / 用挂烫机 / 不需要
- 映射画像字段：设计参数.熨烫需求
- 价值说明：💡 每天熨烫需要专门的熨烫区收纳位

---

## 模块C：种草待确认（动态插入）

| 触发条件 | 种草项 | 推荐理由 | 映射画像字段 |
|---------|--------|---------|-------------|
| Q1=椅子/沙发/地上 | 脏衣分类篮 | 脏衣各归其位，不再乱扔 | 种草待确认.脏衣篮 |
| Q0=手洗 | 洗衣机/洗烘套装 | 解放双手，每天省30分钟 | 种草待确认.洗烘套装 |
| Q2=客厅/卧室临时晾 | 烘干机 | 告别客厅晾衣尴尬，即洗即穿 | 种草待确认.烘干机 |
| Q3=挂衣区不够 | 增加挂衣杆/衣帽间 | 衣服挂起来比叠放更整洁、更易找 | 种草待确认.衣帽间 |
| Q3=换季麻烦 | 百纳箱/真空压缩收纳区 | 换季衣物压缩存放，节省50%空间 | 种草待确认.真空收纳 |
| Q4=每天熨 | 家政柜/洗衣柜 | 集中洗护用品和工具，提升效率 | 种草待确认.家政柜 |

## 输出映射规则

**场景分级：**
- Q1=椅子/沙发/地上 或 Q3含挂衣区不够/找不到 → 🔴核心场景
- Q0=手洗 或 Q2=客厅临时晾 → 🟡次要场景
- Q0=洗烘套装 且 Q3均无 → ⚪无关场景（满意度高）

**痛点清单自动生成：**
- Q1=椅子/沙发/地上 → 痛点="脏衣无处安放，随手乱放"
- Q3=挂衣区不够 → 痛点="衣柜挂区不足，衣服堆叠易皱"
- Q3=找不到 → 痛点="衣物找不到，翻来翻去"
- Q2=客厅/卧室 → 痛点="客厅/卧室临时晾晒，影响美观"

**设计参数提取：**
- Q0=洗烘套装 → 参数="洗烘套装位（上下叠放/并排）"
- Q2=阳台晾晒 → 参数="隐藏式晾衣架/烘干晾衣两用"
- Q4=每天熨 → 参数="熨烫板收纳位"
- Q3=挂衣区不够 → 参数="增加挂衣杆/衣帽间"
- Q3=换季麻烦 → 参数="百纳箱/真空压缩收纳区"
