# 幸之住需求洞察系统 · 迭代路线图

> 当前状态：1.0 MVP 已完成（9+N 场景问卷 + 飞书推送 + 管理后台）
> 本文件用于讨论后续迭代方向，不影响 xingzhizhu-survey/ 目录的 1.0 版本

---

## 候选方向（按投入产出比排序）

### A. AI 自动分析增强（技术中等，体验质变）
- 把客户填写的原始数据传给 Claude API
- AI 自动生成：空间布局建议、选材推荐、预算分配方案
- 设计师收到飞书通知时，附带 AI 初步方案，减少沟通成本
- 投入：1-2 天 / 需要 ANTHROPIC_API_KEY

### B. 客户身份识别（技术简单，业务刚需）
- 问卷链接带参数 `?client=张三&source=企微`
- 后台自动记录客户来源和归属
- 避免"客户填了但不知道是谁"的问题
- 投入：半天

### C. 报告 PDF 生成（技术中等，专业度提升）
- 提交后自动生成带品牌水印的 PDF 报告
- 比"打印网页"更专业，客户留存率高
- 可用 Python 的 `weasyprint` 或 `pdfkit` 实现
- 投入：1 天

### D. 设计师工作台（技术中等，效率工具）
- 从 admin 列表升级为设计师 CRM
- 功能：标记跟进状态（待联系/已量房/已签约）、添加内部备注、导出客户清单
- 投入：2-3 天

### E. 数据看板（技术中等，管理决策）
- 统计所有客户的场景需求分布（如：70% 客户有收纳痛点）
- 热门种草项排行、预算区间分布、区域分布
- 帮助家宝优化供应链和主推方案
- 投入：1-2 天

### F. 问卷自定义后台（技术复杂，长期价值）
- 家宝不用改代码，直接在后台增删改场景问题
- 拖拽调整问题顺序、修改选项文案
- 投入：5-7 天，适合 2.0 大版本

### G. 企微直接集成（技术复杂，体验质变）
- 客户不用点外部链接，在企微对话框里直接答题
- 需要申请企微网页授权或开发小程序
- 投入：3-5 天，依赖企微开放权限

---

## 推荐组合

**短期（1 周内可上线）：A + B + C**
- AI 分析让客户觉得"专业"
- 身份识别解决业务痛点
- PDF 报告提升品牌感

**中期（1 个月内）：D + E**
- 设计师工作台提升内部效率
- 数据看板帮助家宝做决策

**长期（2-3 个月）：F + G**
- 自定义问卷让系统脱离代码依赖
- 企微集成打通获客最后一公里
