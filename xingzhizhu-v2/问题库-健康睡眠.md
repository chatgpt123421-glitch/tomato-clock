# 问题库：健康睡眠（Healthy Sleep）

> 覆盖子场景：遮光隔音、伴侣动线、助眠苏醒、寝具体感
> 原则：睡眠不是闭眼睛，是环境、动线和伴侣关系的总和
> 目标：高敏感用户≤10题，低敏用户≤5题

---

## 前置分流题

**Q0. 卧室现在的遮光情况怎么样？**
- 题型：单选
- 选项：
  - 完全遮光，白天也像黑夜（→ 模块B+C，跳过A遮光）
  - 基本遮光，但边角漏光（→ 完整版全模块）
  - 不遮光，早上被阳光刺醒（→ 完整版全模块，标记"遮光刚需"）
- 映射画像字段：痛点清单.遮光指数

**Q1. 和伴侣的睡眠习惯差别大吗？**
- 题型：单选
- 选项：
  - 差不多，同时睡同时起（→ 模块B+C，跳过D伴侣动线）
  - 作息不同或浅眠易醒（→ 完整版全模块）
  - 独居，不存在这个问题（→ 模块B+C，跳过D）
- 映射画像字段：场景分级.睡眠冲突指数

---

## 模块A：遮光与隔音（遮光不足或噪音敏感用户必填）

**Q2. 晚上睡觉时，有没有被噪音打扰？**
- 题型：多选
- 选项：很安静 / 室外噪音（车/施工/邻居）/ 室内噪音（家人走动/水声）/ 伴侣打呼/翻身
- 映射画像字段：痛点清单.噪音来源
- 价值说明：💡 不同噪音来源对应不同解决方案（隔音窗 vs 隔音门 vs 分床）

**Q3. 夏天开空调睡觉，会不会被冷风直吹？**
- 题型：判断题（会/不会/不开空调）
- 映射画像字段：痛点清单.空调直吹
- 价值说明：💡 冷风直吹容易导致感冒和肌肉僵硬

---

## 模块B：寝具体感（所有用户必填）

**Q4. 对现在的床垫/枕头满意吗？有没有腰酸背痛？**
- 题型：单选
- 选项：满意 / 太硬，腰酸 / 太软，腰疼 / 床垫太旧该换了
- 映射画像字段：设计参数.床垫需求
- 价值说明：💡 床垫是睡眠质量的硬指标，直接决定第二天精神状态

**Q5. 平时习惯什么睡姿？**
- 题型：单选
- 选项：侧睡 / 仰睡 / 趴睡 / 不固定
- 映射画像字段：设计参数.枕头高度
- 价值说明：💡 侧睡需要中高枕，仰睡需要中低枕

**Q6. 睡前会在床上看书/看手机吗？**
- 题型：多选
- 选项：看书（纸质/Kindle）/ 看手机/平板 / 不，躺下就睡
- 映射画像字段：设计参数.床头灯光
- 价值说明：💡 睡前阅读需要柔和的床头阅读灯，不影响伴侣

---

## 模块C：夜间动线（所有用户必填）

**Q7. 晚上起夜频繁吗？起来时需要开灯找路吗？**
- 题型：单选
- 选项：不起夜 / 起夜，摸黑走或开大灯刺眼 / 起夜，有感应小灯
- 映射画像字段：痛点清单.起夜动线
- 价值说明：💡 起夜开大灯会完全唤醒自己，影响再次入睡

**Q8. 希望怎么醒来？**
- 题型：单选
- 选项：传统闹钟 / 自然光渐亮唤醒 / 无所谓
- 映射画像字段：设计参数.唤醒方式
- 价值说明：💡 自然光唤醒更符合人体生物钟，减少起床气

---

## 模块D：伴侣关系（作息不同或浅眠用户必填）

**Q9. 和伴侣的睡眠习惯具体差异在哪？**
- 题型：多选
- 选项：我早睡伴侣晚睡 / 我浅眠易被惊醒 / 已经分床/分房 / 伴侣打呼
- 映射画像字段：痛点清单.伴侣睡眠冲突
- 价值说明：💡 分床不是感情问题，是睡眠质量问题

---

## 模块E：种草待确认（动态插入）

| 触发条件 | 种草项 | 推荐理由 | 映射画像字段 |
|---------|--------|---------|-------------|
| Q0=不遮光 | 100%遮光窗帘/卷帘 | 彻底隔绝光线，提升褪黑素分泌 | 种草待确认.遮光窗帘 |
| Q2=室外噪音 | 隔音窗/隔音窗帘 | 降低30-40分贝，显著提升深度睡眠 | 种草待确认.隔音窗 |
| Q2=伴侣打呼 | 分床/分垫设计 | 互不干扰，各自拥有独立睡眠空间 | 种草待确认.分垫设计 |
| Q4=太硬/太软 | 乳胶/记忆棉床垫 | 贴合身体曲线，缓解腰部压力 | 种草待确认.床垫 |
| Q7=起夜摸黑 | 起夜感应地灯 | 微光指引，不刺眼不影响再次入睡 | 种草待确认.感应灯 |
| Q8=自然光 | 智能窗帘（定时渐亮） | 模拟日出，自然唤醒无起床气 | 种草待确认.智能窗帘 |
| Q3=会直吹 | 空调防直吹挡风板 | 改变风向，避免冷风直吹身体 | 种草待确认.挡风板 |

## 输出映射规则

**场景分级：**
- Q0=不遮光 或 Q2≠很安静 或 Q9含浅眠/分床 → 🔴核心场景
- Q0=基本遮光 且 Q2=很安静 → 🟡次要场景
- Q0=完全遮光 且 Q2=很安静 且 独居 → ⚪无关场景（满意度高）

**痛点清单自动生成：**
- Q0=不遮光 → 痛点="卧室遮光不足，早上被阳光刺醒"
- Q2=室外噪音 → 痛点="室外噪音干扰睡眠"
- Q2=室内噪音 → 痛点="室内噪音干扰（家人走动/水声）"
- Q2=伴侣 → 痛点="伴侣打呼/翻身干扰睡眠"
- Q9=我浅眠 → 痛点="浅眠，易被伴侣动作惊醒"
- Q7=起夜摸黑 → 痛点="起夜无照明，摸黑行走或开大灯刺眼"
- Q3=会直吹 → 痛点="空调冷风直吹，睡觉不舒服"

**设计参数提取：**
- Q0=不遮光 → 参数="100%遮光窗帘/卷帘"
- Q2=室外噪音 → 参数="隔音窗/隔音窗帘"
- Q9=我浅眠 → 参数="独立弹簧床垫/分垫设计"
- Q7=起夜摸黑 → 参数="起夜感应地灯"
- Q8=自然光 → 参数="智能窗帘（定时渐亮）"
- Q5=侧睡 → 参数="中高枕（侧睡支撑）"
- Q5=仰睡 → 参数="中低枕（仰睡支撑）"
- Q3=会直吹 → 参数="空调防直吹挡风板/改变安装位置"
