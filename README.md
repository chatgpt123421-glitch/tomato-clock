# 番茄钟

简洁美观的桌面番茄钟应用，使用 Python + PySide6 开发。

## 功能特点

- 专注计时（默认 25 分钟）
- 短休息（默认 5 分钟）
- 长休息（默认 15 分钟）
- 自动切换工作/休息模式
- 系统托盘最小化
- 完成通知提醒
- 可自定义时间长度

## 运行方式

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python pomodoro.py
```

## 打包成 exe

使用 PyInstaller 打包成独立的可执行文件：

```bash
pyinstaller --onefile --windowed --icon=NONE pomodoro.py
```

打包完成后，可执行文件位于 `dist/pomodoro.exe`。

## 使用说明

1. **开始专注**：点击「开始」按钮，开始 25 分钟专注倒计时
2. **暂停/继续**：随时可以暂停和继续计时
3. **切换模式**：点击「专注/短休/长休」切换不同计时模式
4. **最小化**：关闭窗口会自动最小化到系统托盘
5. **每4个番茄**：完成 4 个专注后会自动建议长休息

## 快捷键

- 双击托盘图标：显示主窗口
